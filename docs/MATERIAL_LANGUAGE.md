# RoughCut Material Language — v0.2

| Family | Value behavior | Ink behavior | Detail behavior |
|---|---|---|---|
| Stone | chunky cool planes | fractures and short stress lines | sparse hatch |
| Cobble | alternating stone values | broken mortar + local cracks | almost no random speckle |
| Deepslate | dark plate shifts | thin plate seams | directional hatch allowed |
| Dirt | warm clod masses | cuts, roots, compressed pockets | calm regions required |
| Grass | broad vegetation masses | blade groups at transitions | biome tint does the color work |
| Oak | alternating warm boards/bark | seams, knots, bark cuts | broad grain only |
| Iron | hard cold planes | panel/scuff marks | bright chips are rare |
| Copper | warm hard planes | seam/scuff marks | oxidation is an accent |
| Glass | mostly transparent | a few reflections | no perimeter grid |
| Ores | host rock dominates | dark cavity around deposit | bright mineral cluster |
| Crafting | warm rough timber | tool-like divisions and cuts | readable utility surface |
| Furnace | rough stone shell | firebox/panel shapes | hard dark openings |
| Barrel | curved/staved wood rhythm | hoops + stave seams | broad grain |

## Shared-world rule
Different families may use different palettes, but all of them should share the same near-black ink logic, stepped value construction, and hand-authored imperfection.
